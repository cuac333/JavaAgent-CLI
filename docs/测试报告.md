## 三、测试覆盖范围

### 3.1 已覆盖的功能点

- **ReAct 循环引擎**：单轮文本、工具调用、迭代上限、连续失败熔断（3 次）
- **工具系统**：全部 8 个内置工具的正常/异常路径
- **安全机制**：10 种 Unix 危险命令 + 10 种 Windows 危险命令检测、工作区隔离、路径越权拒绝
- **审批系统**：只读自动批准、写入需审批、审批缓存、绕过模式
- **会话管理**：保存/加载/消息计数
- **模型客户端**：Mock 模式关键词匹配、工具结果摘要
- **配置管理**：属性文件加载与默认值

### 3.2 未覆盖（建议后续补充）

- SSE 流式解析（需 mock HTTP 响应）
- 上下文压缩（需 mock LLM 摘要）
- Markdown 渲染输出正确性
- Token 计数精度（jtokkit 集成）
- 网络工具 HTTP 请求
- 跨平台路径处理（Windows）
- 插件系统 SPI 发现

## 四、测试方法

- **单元测试**：各工具独立测试，使用 `@TempDir` 提供临时文件
- **集成测试**：Agent + ToolRegistry + MockModelClient 端到端测试
- **隔离性**：`@BeforeEach` 重置工作区根目录，防止测试间状态污染
- **跨平台**：BashToolTest 使用 `@DisabledOnOs(OS.WINDOWS)` 跳过平台特定测试
